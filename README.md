# Predicting Student Academic Performance in the Age of GenAI

This project develops and rigorously evaluates a machine learning solution to
predict student academic performance, specifically addressing the impact of
Generative AI (GenAI) tool usage. Using a dataset of 8,000 student records, it
builds a classifier that flags at-risk students (`Low` / `Medium` / `High`
performance) and a regressor that predicts continuous `final_score`, following
a leakage-safe, fully reproducible pipeline.

See [`reports/final_report.md`](reports/final_report.md) for the full
write-up of the business problem, methodology, results, and recommendations.

## Repository Structure

```
.
├── src/                    # Reproducible source code (data loading, preprocessing, training, evaluation)
│   ├── data_loader.py      # Loads the raw dataset
│   ├── preprocessing.py    # Cleaning, splitting, outlier capping, feature engineering, encoding, scaling
│   ├── train.py            # Model training/comparison utilities (classification + regression)
│   ├── evaluate.py         # Evaluation utilities
│   └── pipeline.py         # End-to-end pipeline entry point
├── notebooks/               # Exploratory analysis and the full capstone notebook (Steps 1-5)
├── data/
│   └── raw/                 # Raw dataset (ai_impact_student_performance_dataset.csv)
├── models/                  # Persisted trained model artifacts (generated by src/pipeline.py)
├── reports/                  # Final written report and generated evaluation metrics/comparisons
├── tests/                    # Unit tests for the preprocessing pipeline
├── requirements.txt
└── README.md
```

## Getting Started

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the reproducible pipeline

```bash
python -m src.pipeline
```

This loads `data/raw/ai_impact_student_performance_dataset.csv`, applies the
full leakage-safe preprocessing and feature engineering pipeline, trains and
compares multiple classification and regression models, and saves:

- Champion classifier and regressor (`models/*.pkl`)
- Fitted scaler and label encoder (`models/scaler.pkl`, `models/label_encoder.pkl`)
- Model comparison tables and evaluation metrics (`reports/*.csv`, `reports/metrics.json`)

### 3. Explore the analysis notebook

The full exploratory analysis, hypothesis testing, and explainability/bias
auditing steps are documented in:

```
notebooks/Gerric_Gomez_Capstone_Project_Pillar_5_Steps_1to5.ipynb
```

### 4. Run the tests

```bash
pytest tests/
```
